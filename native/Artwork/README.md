# App Icon

`app-icon.png` is the selected N concept: a red casserole pot with an ivory lid,
yellow knob and white steam on a full-bleed pink background. No green, text,
transparent margins or baked-in rounded corners.

Created with the built-in image generation tool. Prompt: refine concept N from
the comparison board into one standalone square iOS icon; preserve the rounded,
softly sculpted cooking pot, pink/red/yellow/ivory palette and top-left lighting;
extend opaque pink to all four corners and keep the pot and steam inside the
safe area, with no labels or surrounding icons.

Run `pnpm run native:resources` to regenerate all iPhone, iPad and App Store
sizes. Run `pnpm run native:check` to verify their hashes, dimensions and opacity.
The source artwork is not included as a separate app resource.
